# MLOps Breast Cancer Classification Pipeline

## Overview

This project demonstrates a complete end-to-end MLOps pipeline for
Breast Cancer Classification.

## Architecture

Dataset
↓
DVC
↓
Data Processing
↓
Model Training
↓
MLflow Experiment Tracking
↓
Best Model
↓
MLflow Model Registry
↓
FastAPI
↓
Docker
↓
GitHub
↓
GitHub Actions

## Models

Three machine learning models are trained:

1. Logistic Regression
2. Random Forest
3. Support Vector Machine

## Technologies

- Python
- Scikit-learn
- Pandas
- DVC
- MLflow
- FastAPI
- Docker
- Git
- GitHub Actions
